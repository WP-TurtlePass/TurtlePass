# 디지털 투어패스

## 소개

거북섬을 배경으로 허구의 혜택을 탐색·발급·사용하는 수업용 디지털 투어패스를 기획한다. 현재는 문서 전용 프로젝트이며 실행 가능한 앱·DB 스키마·테스트는 아직 없다.

[요구사항](spec.md) → [설계·검증](plan.md) → [작업 현황](tasks.md) 순서로 읽는다. 기술 스택과 구현 단계는 설계 문서에서 관리한다.
